# 发票业务竞品调研 · 执行计划

> 日期：2026-07-18 · 目标：为未来在海南基于 IIP 系统做发票相关业务提供竞品全景与落地参考

## 背景（本系统现状）

IIP 发票积分平台 v1.0.0：小程序上传发票 → 管理员人工审核 → 按面额×活动比例发积分 → 积分商城兑换门票/优惠券 → 商户核销。基于安阳"发票核验+积分兑换"模式。
本期未做：发票 OCR、税局真伪查验（预留接口位）、支付/退款/券转赠。
