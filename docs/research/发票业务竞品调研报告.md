# 发票业务竞品调研报告

> 版本：v1.0 · 调研日期：2026-07-18
> 目的：为 IIP 发票积分平台未来在海南落地发票相关业务提供竞品全景、政策依据与路线图参考
> 调研方法：13 路并行网络调研（竞品厂商 7 路、促消费活动案例 2 路、海南专题 2 路、政策底座 1 路、能力供应商 1 路），关键结论均附公开信息来源；查不到公开数据处均已如实标注。

## 0. 一页看懂（执行摘要）

1. **市场上"发票业务"分两大类**：一类是 **B 端发票/财税数字化服务**（百望云、航天信息诺诺、用友、金蝶、高灯、大象慧云、云砺票易通、国票发票通等），实现"开票—收票—查验—报销—申报—归档—风控"全链路，靠 SaaS 订阅 + 按量计费 + 项目制赚钱；另一类是 **G 端"发票+促消费"活动**（有奖发票/发票抽奖/发票积分），由政府出资、银联商务/支付宝/京东科技等承运——IIP 属于第二类的"积分制"变体。
2. **与 IIP 最直接对标的是银联商务的"票根经济"方案**：安阳"发票换门票"（OCR 识别 → 实时核验 → 面额 1:1 积分 → 兑换景区门票）与 IIP 业务闭环几乎同构，且该方案已在无锡、开封、南宁等 14 个活动复制。IIP 当前的人工审核模式落后于其"OCR+实时验真"标配。
3. **海南正处政策窗口期**：海口已入选全国 50 城有奖发票试点（2026-02-12 至 07-31，限 ≥100 元数电票，单张最高 800 元），截至 6 月底审核发票 503.83 万张、发红包超 1.2 亿元、带动消费 41.6 亿元。官方试点做"概率性抽奖"，**IIP 的"确定性积分返还+商城兑换"是错位互补形态**，且海南本地尚无发票积分类案例。
4. **进入海南市场的硬门槛是"查验验真"**：所有官方活动方案均内置 OCR + 税局查验 + 防红冲 + 频次限制。IIP 预留的 OCR/查验接口位必须尽快落地（OCR 市价 0.03–0.15 元/次、验真 0.12–0.30 元/次，均有免费额度可试点），否则无法进入政府服务商征选视野。
5. **两条红线**：① 政策依赖单点业务风险极大（诺诺网营收三年下滑 65%、欠薪裁员）；② 发票流量/广告变现会被监管点名（诺诺 3·15 事件）。IIP 应坚持"向政府/商户收运营服务费"的清洁模式。

## 1. 市场全景：发票业务的五类玩家

| 类别 | 代表玩家 | 实现的核心业务 | 收费模式 |
| ---- | -------- | -------------- | -------- |
| 发票数字化平台（头部） | 百望云（06657.HK）、航天信息/诺诺 | 销项开票、进项管理、供应链协同、财税 SaaS、数据服务 | 订阅+按量+项目制；基础开票免费引流 |
| ERP 系财税模块 | 用友（税务云/YonSuite）、金蝶（发票云/AI 税务云） | 业财税票档一体化、乐企直连、全税种申报 | 按税号/模块订阅+实施+项目制 |
| 发票数字化新锐 | 高灯科技（腾讯系）、大象慧云（京东系）、云砺票易通 | 交易鉴证、场景化开票（ETC/加油）、进项发票池、供应链协同 | 按交易规模抽佣+订阅+项目制 |
| 中小 SaaS / 开放平台 | 国票发票通、诺诺开放平台、垂直"扫码开票"玩家 | 扫码/API 开票、发票查验、归集、一键申报 | 基础四项免费+增值订阅（约 300–600 元/税号/年）+API 计费 |
| 费控报销 | 合思（易快报）、分贝通、每刻、汇联易 | 发票采集/OCR/查验/查重/报销/入账/归档 | 按账号订阅（如每刻 360 元/账号/年）+实施+商旅佣金 |
| **G 端促消费承运**（与 IIP 同类） | 银联商务、支付宝、京东科技、地方国资数科公司 | 有奖发票/发票抽奖/票根经济的系统建设与运营 | 政府购买服务（项目制），C 端免费 |

**关键格局判断**：B 端发票服务市场与 IIP 短期无正面竞争（他们向企业财务部门收费，IIP 向政府/商户收费，发票在 IIP 中是"权益凭证"而非"报销凭证"）；但 B 端厂商的能力清单（查验、查重、归集、风控）就是 IIP 的功能路线图参照系。G 端促消费承运才是真正的竞品战场，目前由银联商务一家独大。

## 2. 头部竞品逐个分析

### 2.1 百望云（百望股份，06657.HK）

- **背景**：2015 年成立，阿里为第一大机构股东（IPO 前 11.87%），2024 年港股"电子发票第一股"。2025 年营收 7.29 亿元（+10.5%）首次扭亏；累计处理发票 231 亿张。
- **实现的业务**：① 云化财税数字化（占收入 54%）：数电票/税控开票（扫码、H5、API 批量）、进项归集查验抵扣、2/3 单匹配、纳税申报、电子会计档案、供应链协同（对账/开票/红冲双边协同）、开放平台 API、OFD 版式信创产品；② 数据智能业务（占 46%）：基于发票数据的助贷导流、企业信用报告、风控服务，2025 年起转型 AI（金盾交易智能体、税务合规数字顾问等）。
- **模式**：基础开票/版式服务免费（1700 万非付费用户）→ 增值订阅 + KA 私有化项目制 + 数据服务按调用收费。
- **借鉴**："免费基础服务获客、增值服务收费"；发票数据二次变现（消费洞察、政策评估）是更大的生意；与地方国资/数据集团共建换取区域市场（无锡模式）。

### 2.2 航天信息 & 诺诺网

- **背景**：航天信息（600271.SH）是金税工程税控系统承担单位，历史双寡头之一；数电票替代税控设备后营收三年 125.75 亿 → 55.54 亿元，2025 年亏损 7.46 亿。诺诺网（航信持股 64.3%、蚂蚁持股 17.5%）营收三年下滑约 65%，2025 年被 3·15 点名（开票后跳转抽奖广告），2026 年被曝欠薪裁员。
- **实现的业务**（诺诺发票平台）：手工/批量/扫码/API 开票、支付即开票、税盘托管；四要素真伪查验、进项勾选认证；报销防重复、一键生成凭证申报；电子归档；餐饮/酒店/景区/停车等行业方案；开放平台 API；发票贷（浦发案例：凭开票数据授信最高 100 万）。
- **模式**：税控硬件+年费（历史）→ SaaS 按税号订阅（渠道公示数电对接 599 元/年/税号）+ 项目制 + 金融导流。
- **借鉴**：① 餐饮小票码、景区门票码、停车订单关联开票的 C 端链路可直接对标 IIP 上传入口；② **反面教材**——政策依赖与流量变现两条红线（见 §7）。

### 2.3 用友（税务云 / YonSuite）

- **实现的业务**："业财税资档一体化"——乐企直连自动开票（成都高投首张数电票案例）、多通道进项一键归集、查重查验、抵扣勾选；36 省市一键报税（成功率 98%）；税务风控驾驶舱；电子会计档案；OCR 识票自动填单。宣称服务 20000+ 大中型企业、57 家一级央企。
- **公开定价**（YonSuite，按税号/年）：电子发票/票据中心 ¥0（引流）、销项管理 ¥1,400、进项管理 ¥2,000、增值税申报 ¥1,300、税务分析 ¥2,000、档案 ¥2,000/全宗；电票直连 ¥30,000/银行/年；税票数据分析报告 ¥380/份。
- **借鉴**："基础免费 + 模块付费"的定价结构；查验能力应对标税局接口与税务数字账户，而非自建 OCR 体系；先做标杆（一个政府试点或大型商圈）再下沉复制。

### 2.4 金蝶（发票云 / AI 税务云）

- **实现的业务**：多入口开票（订单/合同/电商/API）+ 14 种特殊票种；**"五合一"开票通道（税控/区块链/乐企直连 1–2 秒每张/36 省市 RPA/第三方）——ERP 行业首家乐企联用服务商（305 个接口）**；7 种收票采集 + OCR 识别 30+ 票种（含境外票）；20+ 项合规校验（真伪、查重、连号、黑名单）分级管控；抵扣勾选自动化；一键报税（800+ 申报表模板）；电子会计档案首批试点。服务 6 万+ 企业、累计 2 亿+ 张。
- **模式**：订阅 + 超量按张加收；查验按次约 0.2 元/次；乐企接入服务约 3 万元/户（把行业 40 万+ 成本打到 3 万）。标杆：海信（560 企业 175 税号）、长隆（48 个开票场景）、百胜中国。
- **借鉴**：把"查重+真伪+抬头校验"封装为独立可插拔合规层、按量计费；校验结果分级（严控/预警/放行）而非一刀切，适配 C 端上传体验。

### 2.5 高灯科技 & 大象慧云（新锐）

- **高灯科技**（腾讯发起，B 轮超 10 亿元）：定位"交易数字化基础设施"——高灯云（支付路由、交易鉴证风控、税务直连，"身份/交易/资金/发票"四流合一）；ETC 助手（首个互联网 ETC 平台，通行即开票）；加油（驿能）、费控（企票夹/微报销/腾讯云费控）、灵工完税、助农；G 端与税务局共建交易鉴证（普洱农贸市场区块链发票）。模式：按交易规模/笔数抽佣 + SaaS + G 端项目制。
- **大象慧云**（航信+京东合资，累计开票 100 亿+ 张）：I-Tax（集团）/优税（中小）双体系——纸电一体开票、进项发票池（签收→查验→入账→抵扣）、报销机器人+OCR、全税种一键申报、供应链协同（TATA 案例）。
- **借鉴**：① "支付即开票、交易即鉴证"卡位高频场景（海南：景区、免税周边、加油充电）——把"上传发票攒积分"前置为"支付→自动归集→自动积分"；② 把 IIP 包装为"促消费+税收共治"的政务方案争取税务/商务背书；③ 核销环节若接入分账结算，可从审核工具升级为交易基础设施。

### 2.6 中小 SaaS 与开放平台（云砺票易通、国票发票通等）

- **云砺（票易通）**：C 系列融资近 2 亿美元。进项平台：多入口采集 + 国税查验 + 敏感词/黑名单风控 + 抵扣勾选 + 发票池去重 + 业务单据匹配。大客户项目制（某餐饮连锁 1000+ 门店进项仅 3 人处理）。
- **发票通（国票信息，非百望系）**：国家电子发票标准组成员、首批乐企直连服务商。版式生成/打印/查询/交付**四项基础服务永久免费**；增值覆盖智慧报销、一键申报、电子档案、开放平台 API（dev.fapiao.com）。客户含国家电网、顺丰、国航/海航等。
- **诺诺开放平台**：开票/查验/智能编码 API+SDK；电子发票服务费约 300 元/年（网络问答口径）。垂直玩家（如餐饮"微信闪开"）：3 秒扫码出票、按年收费。
- **"票小蜜"未查到可靠公开信息**（仅第三方软文提及，主体与定价无法核实）。
- **借鉴**：OCR/查验直接买 API 填入 IIP 预留接口位；"归集—查验—去重—状态监控"流水线平移为 IIP 用户发票池，对作废/红冲票扣回积分；商户端用"静态码+小程序"零硬件接入核销。

### 2.7 费控报销赛道（合思、分贝通、每刻、汇联易）

- 共性标配：拍照 OCR 识票（每刻支持 10+ 票种"群拍群读群验真"）、微信卡包/支付宝发票管家/消费平台自动归集、直连税务底账验真、电子发票查重、作废/红冲状态查询、价税分离与进项抵扣、AI 审核（每刻 13+ 合规检查/56+ 规则）、自动凭证 + 电子会计档案（响应电子凭证会计数据标准）。
- 模式：SaaS 订阅 + 实施 + 商旅/支付佣金。**每刻公开价：360 元/账号/年，实施与对接各 3000 元/人天，OCR 验真按版本赠 100–200 次/人/年、超额另计**；其余三家询价制。合思 7000+ 付费企业，软银/红杉投资；分贝通 C 轮 9250 万美元（高瓴、腾讯）。
- **借鉴**：发票风控"机器初审+人工复核"；OCR 成本模型参考"按次赠送+超额计费"；未来 IIP 可向商户叠加发票归集、电子凭证归档、经营分析等 B 端增值服务作为第二收入曲线。

## 3. 最直接对标：有奖发票 / 发票促消费案例库

### 3.1 政策脉络与最新一轮试点

- 2017–2018 年：北京率先在四行业重启电子化摇奖（微信红包兑付），扩至上海、湖北（2018 年奖金 3000 万、季度大奖 40 万）、深圳、陕西等地。
- **2025-12-31：财政部、商务部、税务总局联合印发《关于开展有奖发票试点工作的通知》（财建〔2025〕484 号）**：约 50 个地市级以上城市试点 6 个月，全国奖补资金 100 亿元；限个人实名抬头、单张含税 ≥100 元数电票、覆盖零售/餐饮/住宿/文旅/娱乐/体育/居民服务等八大行业，单张奖金最高 800 元。2026-01-23 公示 50 城名单（含北上广深、**海口**）。

### 3.2 标杆案例（与 IIP 同构度排序）

| 案例 | 主办方/承运 | 玩法规则 | 规模与效果 |
| ---- | ----------- | -------- | ---------- |
| **安阳"发票畅游 乐享安阳"**（IIP 原型） | 安阳市政府 / **银联商务"票根经济"方案** | 小程序上传 → OCR 识别 + 实时核验 → 面额 1:1 积分 → 兑换殷墟、红旗渠等 7 景区门票（2025-12 至 2027-05） | 同方案已复制到无锡"苏超"、开封、南宁马拉松等 14 个活动 |

| 成都+泸州 | 地方政府/平台 | 双城联动 | 上传 4125.7 万张、票面 209.3 亿、471.5 万人参与、发奖 3 亿+，**拉动比 1:70** |

### 3.3 模式要点提炼

1. **谁掌握入口与核验通道，谁就是承运方**：上海公开遴选确定银联为全市统一平台；武汉遴选微信；湖州由城投数科自建小程序（聚合支付宝+微信双入口）。
2. **奖励结构标配**：即时小额（24h 到账）+ 定期/延时大额（T+15 二次核验发票状态后兑付，防红冲套利）。
3. **风控标配**：实名抬头校验、多平台防重复上传、频次限制（每天 3–5 张/每月 45 张）、虚开/拆分开票封禁、红冲追回、公证开奖、奖金个税代扣。
4. **运营不是小事**：石家庄、邯郸曾因体验问题暂停云闪付渠道优化；银联配 95534 热线+智能客服（春节 10 万+ 通咨询）。
5. **单一抽奖吸引力有限，券联动放大杠杆**：厦门"发票红包+消费补贴+商家叠加优惠"三重福利拉动 1.37 亿；南阳"发票抽奖+银行券"。

## 4. 海南专题

### 4.1 政策环境

- **自贸港税制**：2025-12-18 全岛封关运作；"双 15%"（鼓励类产业企业所得税 15%、高端紧缺人才个税超 15% 部分免征）已延续至 2027 年底；零关税商品税目比例封关后 21% → 74%；**销售税（增值税等简并）仍在研究中、未落地**——若落地将重构"以票管税"逻辑，是产品的颠覆性变量。
- **数电票落地**：海南 2023-04-27 起数电票试点（无需税控设备/票种核定）；2025 年起机动车、铁路轮渡全面电子化；财政部 2025-05 发布数电票会计数据标准（XML 报销入账归档）。
- **市场热度**：封关后至 2026-03-31 新增经营主体 9.68 万家（企业 8.02 万家，同比 +100%）。
- **有奖发票**：海口入选 50 城（2026-02-12 至 07-31）；银联商务已在海口上线"支付即开票、开票即抽奖"（打通 E 开票平台与云闪付，数百家商户）；京东科技对外输出"发票抽奖兑付系统"方案。

### 4.2 本地市场案例

- **消费券**：省级"购在海南"欢乐节券（云闪付）、海口 2025 新春 2500 万券（抖音/美团/云闪付多渠道）、省旅文厅酒店券 1000 万（公开征集发放平台）、2026 年 3000 万"机票+"文旅券（酷游海南小程序+云闪付）。
- **离岛免税**：6 家主体 12 家门店，中免为龙头；政策 15 年累计销售 2864 亿元；封关后首个春节 27.2 亿元（+30.8%）；市县政府联动中免发免税券（秀英区 560 万等）。
- **发票积分类活动：海南未检索到本地案例**——目前主流形态是"有奖发票抽奖"，对 IIP 是差异化空间而非同质竞争。

### 4.3 IIP 在海南的切入点

1. **错位定位**：官方试点是"概率性现金抽奖、活动期有限"；IIP 是"确定性积分返还、可沉淀用户与二次消费"。主打试点未覆盖的景区/门票/商户联营场景，或**承接 2026 年 7 月底试点结束后的常态化运营空档**。
2. **承运技术服务商路线**：参考湖州（城投数科自建）、开封（银联商务定制）模式，IIP 可输出审核后台+积分商城+核销模块，与云闪付/支付宝入口互补联运，而非自建平行入口对抗。
3. **主体落地享红利**：在海南设立实质性运营主体（现代服务/高新技术属鼓励类），享 15% 企业所得税，便于承接市/区级项目制订单。
4. **渠道联动**：积分商城对接文旅券/免税权益包，嵌入消博会、欢乐节等节点运营。

## 6. 能力缺口与采购建议（OCR / 查验比价）

IIP 现状：人工审核为主，已预留 `image_url` 与查验接口位。可采购方案对比：

| 供应商 | 能力 | 价格（公开刊例） | 免费额度 |
| ------ | ---- | ---------------- | -------- |
| 百度智能云 | 增值税发票识别（全字段，宣称 99%）、验真 | 识别 0.03–0.10 元/次；验真 0.20–0.24 元/次 | 识别每日 500 次 |
| 腾讯云 | 发票识别、发票核验（独立产品）、混贴识别 | 识别 0.06–0.15 元/次；核验 0.25–0.30 元/次 | 识别每月 1000 次；核验开通送 50 次 |
| 阿里云 | 票据识别、VerifyVATInvoice 核验 | 识别约 0.04–0.08 元/次 | 按量阶梯 |
| 合合 TextIn | 30+ 票种、数电票、单页多票切分、OCR+验真一体 | 识别低至 0.05 元/次 | 新用户 100 次 |
| API 市场（数脉/数链云/聚合等） | 四/五要素验真 | 约 0.12–0.30 元/次（需企业实名+场景审核） | 部分有试用 |

**采购与落地策略**：

1. **封装适配层**：按"百度/腾讯/阿里比价 + TextIn 备选"做多供应商适配，保留切换与容灾；先用免费额度跑通 MVP。
2. **分层风控控成本**：促消费单票价值低、量大——"OCR 要素提取 + 本地查重/规则校验"为主，仅对高面额、抽检样本、兑换门槛以上发票调验真 API，单票风控成本可压到几分钱。
3. **体验设计**：OCR 结果允许用户/审核员修正（四要素 99% 作验收基准），识别失败转现有人工审核兜底；必须支持数电票与单页多票。
4. **反套利规则固化**（来自各地方案标配）：同票防重（已有 uk 幂等）、单用户频次/金额上限、红冲/作废票追回积分、大额权益 T+N 二次核验后发放。

## 7. 风险与红线

1. **政策依赖风险**：诺诺营收三年腰斩、欠薪裁员——单一政策红利不可持续；IIP 应把政府项目制与商户长效运营双轮并行。
2. **流量变现红线**：诺诺开票后跳转抽奖广告被 3·15 点名——积分兑换链路杜绝诱导性广告/数据倒卖；发票数据使用须明示授权。
3. **巨头替代风险**：银联商务"票根经济"方案已标准化并复制 14 个活动、京东科技输出抽奖兑付系统——IIP 若不补齐 OCR+查验，在政府征选中会被直接替代。
4. **高并发运营风险**：石家庄/邯郸曾因体验问题暂停渠道——活动上线前需压测与客服预案。
5. **税制改革变量**：海南销售税若落地，发票形态与"面额×比例"积分基础可能变化——票种与税目适配应做成可配置层。

## 8. 对 IIP 的路线图建议

**短期（0–3 个月，补能力）**
- 接入 OCR（免费额度起步）+ 查验 API（分层调用），审核从"纯人工"升级为"机审为主、人工抽检"；
- 固化反套利规则：频次上限、红冲追回、大额 T+N 发放、实名抬头校验；
- 小程序上传体验对齐标杆：拍照 OCR 自动回填，两步提交。

**中期（3–9 个月，切海南）**
- 注册海南实质性运营主体（双 15% 红利），组建 BD 对接市县商务/旅文/税务部门；
- 以"积分制促消费长效方案"错位申报政府合作：承接海口试点结束后的常态化运营，或面向非试点市县/商圈/景区做联营积分活动；
- 探索与收单机构/云闪付合作"支付即上传、支付即积分"；商户端零硬件核销推广；
- 积分商城引入银行券、免税权益、文旅券联动（参照厦门三重福利）。

**长期（9 个月以上，建壁垒）**
- 商户侧增值服务：发票归集、对账报表、电子凭证归档（对齐财会〔2025〕9 号）、经营数据分析——第二收入曲线；
- 数据资产化：消费发票数据服务政府促消费政策评估与商户洞察（参照百望路径，合规授权前提下）；
- 跟踪销售税改革与乐企门槛，票种/税目可配置化。
